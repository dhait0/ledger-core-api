# Decisions

## Use NestJS now

The previous demos covered UI, automation, and lightweight REST routes. This repo introduces a real backend framework and stronger service boundaries.

## Use PostgreSQL through Docker Compose

Docker Compose gives reviewers a realistic local infrastructure path without requiring cloud services.

## Keep the domain synthetic

Reconciliation is a recognizable enterprise workflow, but every record, system name, and event is fake.

## No frontend application

This repository is intentionally backend-first. Screenshots document architecture instead of a product dashboard.
