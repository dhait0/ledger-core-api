# Mission

Build a bilingual NestJS, Prisma, PostgreSQL backend demo that demonstrates enterprise API architecture without exposing private systems.

## Product rules

- Focus on backend quality, API contracts, Docker, Prisma schema, and operational documentation.
- Use mock reconciliation data only.
- Keep English and Spanish context in README, docs, and API response metadata.
- Do not include real credentials, customer names, internal schemas, or business logic.
- This repo should feel like a service a senior engineer could hand to an enterprise client.

## Repository standards

- Include `README.md`, `docs/`, `LICENSE`, `.env.example`, `.gitignore`, and screenshots.
- Keep TypeScript strict mode enabled.
- Document architecture, implementation, decisions, and future improvements.
